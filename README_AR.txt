HM BEAUTY SC - النسخة المطوّرة (PWA)

المزايا:
- إضافة وتعديل وحذف المنتجات.
- تصوير المنتج بالكاميرا أو اختيار صورة من الهاتف، مع ضغط الصورة لتقليل حجم التخزين.
- حفظ الباركود ومسحه بالكاميرا في المتصفحات الداعمة لـ BarcodeDetector.
- تسجيل ثمن الشراء وثمن البيع والكمية وحد تنبيه المخزون.
- حساب ربح القطعة، قيمة المخزون بسعر الشراء، الربح المتوقع وقيمة المبيعات التقديرية.
- البحث بالاسم أو الباركود، وإنقاص قطعة عند البيع.
- تصدير نسخة احتياطية JSON تشمل صور المنتجات، واسترجاعها.
- واجهة عربية RTL ودعم التثبيت كـ PWA والعمل دون اتصال بعد أول تحميل.

مهم:
1) هذه نسخة ويب تقدم تجربة تطبيق PWA وليست ملف APK أصلياً.
2) البيانات تحفظ محلياً في المتصفح على نفس الهاتف. لا تمسح بيانات المتصفح قبل تصدير نسخة احتياطية.
3) رفع الملفات إلى استضافة HTTPS ضروري لتشغيل الكاميرا وService Worker. يمكن نشرها على GitHub Pages.
4) بعد النشر افتح الرابط عبر Chrome على Android ثم القائمة > تثبيت التطبيق أو إضافة إلى الشاشة الرئيسية.
5) مسح الباركود يعتمد على دعم BarcodeDetector في المتصفح؛ عند عدم توفره أدخل الباركود يدوياً.
6) الصور تضغط إلى حد أقصى 640px. كثرة الصور قد تستهلك مساحة المتصفح؛ صدّر نسخاً احتياطية بانتظام.
7) الاسترجاع يستبدل قائمة المنتجات الحالية بعد طلب التأكيد.

ملفات المشروع: index.html, style.css, app.js, manifest.webmanifest, sw.js, icon.svg
